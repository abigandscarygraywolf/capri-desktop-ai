# Capri — текстовый чат и несколько профилей

Это оригинальный Capricorn с двумя дополнительными возможностями.

## Запуск на Windows 11
1. Распакуйте ZIP в папку с доступом на запись.
2. Выполните оригинальный `setup.bat`, если зависимости ещё не установлены.
3. Для локальной нейросети выполните оригинальный `setup_ai.bat` (или настройте Ollama согласно README оригинала).
4. Запустите `run.bat`.
5. Откройте меню из иконки Capri в трее: **Чат и команды…** или нажмите **Ctrl+Alt+C**.
6. В том же меню выберите **Профили пользователей…** для создания и переключения профилей.

## Как работает чат
Текст передаётся в оригинальный обработчик `actions.handle()`. Распознанные команды исполняются, остальные сообщения передаются в настроенную нейросеть. Ответы появляются в окне чата и озвучиваются. Команды изменяют состояние компьютера так же, как оригинальные голосовые команды — проверяйте их перед отправкой.

## Профили
Имена и род обращения хранятся в `profiles.json` рядом с программой. При переключении профиля контекст текущего диалога Ollama и Claude очищается, чтобы не смешивать разговоры разных пользователей. История сообщений в окне не сохраняется между перезапусками; профили не защищены паролем. Старое окно «Как ко мне обращаться» заменено менеджером профилей. Остальные настройки оригинального Capricorn сохранены.

## Ограничения
Проверен синтаксис Python, но запуск на Windows и работа микрофона/трея в данной среде не проверены. Если Ctrl+Alt+C занято другой программой, открывайте чат через трей. В проекте сохранены исходные ассеты и оригинальная лицензия.
